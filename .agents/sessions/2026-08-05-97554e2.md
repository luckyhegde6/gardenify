## Key lessons

- **An initial-route `<Redirect>` is not an auth guard** — it only runs at app launch. Watch auth state in the root layout (`useSegments` + `router.replace`).
- **`useSegments()` narrowing can trip on stale typed-routes** — use `segments.join("/").includes(...)` instead of tuple indexing.
- **EAS submit can hang at "Computing project fingerprint"** — use `EAS_SKIP_AUTO_FINGERPRINT=1`; cancel duplicate builds with `eas build:cancel <id>`.
