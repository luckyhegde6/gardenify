## Key lessons

- **Vercel `lstat ENOENT`**: for GitHub-linked Vercel projects the deploy manifest derives from the git tree; excluding git-tracked files via `.vercelignore` breaks sync. Exclude only untracked/generated files.
- **`vercel build` + `--prebuilt`** creates `.vercel/python/.venv` artifacts the manifest references but `.vercelignore` excludes → more ENOENT. Use direct `vercel deploy --prod`.
- **Deploy backend as part of the release flow** (`needs: create-release`), not on every push — tests → tag → release APK → deploy backend.
