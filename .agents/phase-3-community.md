# Phase 3: Community & iOS

> Goal: Add social features, offline support, and iOS deployment.

## Features

- [ ] Plant collection (virtual garden)
  - [ ] Collected species with photos and scan dates
  - [ ] Stats: total species, rarest find, most scanned
  - [ ] Achievement badges
- [ ] Push notifications
  - [ ] Install `expo-notifications`
  - [ ] Seasonal plant tips
  - [ ] Reminders to scan new plants
- [ ] Offline mode
  - [ ] Cache recent identifications for offline viewing
  - [ ] Queue scans when offline, process when online
  - [ ] Offline-first UI with loading states
- [ ] Community feed
  - [ ] Share observations publicly
  - [ ] Like/comment on others' finds
  - [ ] Trending species in your area
- [ ] iOS support
  - [ ] Configure iOS build in eas.json
  - [ ] Apple Sign-In integration (required for App Store)
  - [ ] iOS-specific testing
  - [ ] TestFlight beta distribution
- [ ] App Store / Play Store submission
  - [ ] Store listing (screenshots, description, graphics)
  - [ ] Privacy policy
  - [ ] Data safety form
  - [ ] Content rating
  - [ ] Submit for review
