Data Flow

sequenceDiagram
    participant User
    participant App
    participant Backend
    participant PlantNet
    participant Supabase

    User->>App: Capture plant photo
    App->>App: Validate image (type, size)
    App->>Backend: POST /api/identify
    Backend->>Backend: Validate request
    Backend->>Backend: Check user quota
    Backend->>PlantNet: Identify species
    PlantNet-->>Backend: Return results
    Backend->>Backend: Parse response
    Backend->>Supabase: Save identification
    Backend-->>App: Return results
    App->>App: Display species match
    User->>App: View details / Save favorite

    Note over Backend,Supabase: User can view history
    App->>Supabase: GET /identifications
    Supabase-->>App: Return user's history
