🌿 Gardenify API Flows

Plant Identification Flow

flowchart TD
    A[User captures photo] --> B{Validate image}
    B -->|Invalid type| C[Show error: Unsupported format]
    B -->|Too large| D[Show error: Max 10MB per image]
    B -->|Valid| E[Send to backend]
    E --> F[Backend validates request]
    F --> G{Check user quota}
    G -->|Quota exceeded| H[Show error: Daily limit reached]
    G -->|Quota OK| I[Forward to PlantNet API]
    I --> J{PlantNet response}
    J -->|Success| K[Parse species results]
    J -->|Error| L[Show error: Service unavailable]
    K --> M[Save to Supabase]
    M --> N[Display results to user]

Authentication Flow

sequenceDiagram
    participant User
    participant App
    participant Supabase

    User->>App: Enter email + password
    App->>Supabase: signInWithPassword()
    Supabase-->>App: JWT + session
    App->>App: Store in SecureStore
    App->>Supabase: GetUser profile
    Supabase-->>App: User metadata
    App->>App: Auto-create profile if new
    App-->>User: Redirect to Home

    Note over User,Supabase: Session refresh
    App->>Supabase: getSession()
    Supabase-->>App: Refreshed JWT
    App->>App: Update SecureStore

Image Storage Flow

flowchart TD
    A[Image selected] --> B[Validate format/size]
    B --> C[Compute SHA-256 hash]
    C --> D{Hash exists?}
    D -->|Yes| E[Reuse existing URL]
    D -->|No| F[Upload to Supabase Storage]
    F --> G{Upload success?}
    G -->|No| H[Retry up to 3 times]
    H --> F
    G -->|Yes| I[Get public URL]
    I --> J[Store URL in identification]
    E --> J
    J --> K[Continue identification]

Error Handling

Error Type HTTP Code User Message Action
Invalid image format 400 "Unsupported image format" Prompt to retake photo
Image too large 400 "Image exceeds 10MB limit" Compress or retake
Quota exceeded 429 "Daily limit reached" Show quota reset time
PlantNet down 502 "Service temporarily unavailable" Retry later, queue if offline
No species found 200 "Could not identify plant" Suggest better photos
